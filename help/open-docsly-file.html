Open a .docsly file

A .docsly file carries documents, folders and their tags from one Docsly to another — a passport for a family member, a folder of contracts for a lawyer, your whole vault for a new phone. It opens only in Docsly, on iPhone, iPad or Android.

How to open it

  • Tap the file in Files, Mail, Gmail or a messenger and choose Docsly.
  • Share it to Docsly from the app it arrived in.
  • In Docsly: the “…” menu on the Folders or Files tab → Import .docsly, or Settings → Data & storage → Backup & Restore → Import from file.

What happens next

  1. If the file has a password, Docsly asks for it — the one the sender set. If not, it asks whether to import the file.
  2. Choose Import everything, or Choose… to take only some folders.
  3. If the file carries profiles, choose Into the current profile or By the file’s profiles. Profiles with the same name and colour are not duplicated.

The documents are added to what you already have; nothing is replaced. Documents sent without a folder land in the Inbox. The import goes into the vault that is open at that moment.

About the password

When sharing as .docsly, a password is optional. Without one, anyone who has Docsly and the file can open it, so set one whenever the file travels through a messenger or email — and send the password some other way. A file made with Export to file always has a password.

A wrong password changes nothing: the file stays, and you can open it again with the right one. A forgotten password cannot be recovered — ask the sender for a new file.

If Docsly says “This is not a Docsly file”

The file is damaged or is not a .docsly file at all — for example, it was renamed. Ask the sender to share it again.

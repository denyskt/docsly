Restore a backup

You need the backup and the passphrase it was made with. Nothing else — no account with us, because there is none.

From Google Drive or iCloud

  1. Open Settings → Data & storage → Backup & Restore. On Android, tap Sign in with Google with the account the backup was made under; on iPhone, use the same iCloud account.
  2. Under Restore, pick the backup: the restore icon on its card on Android, the arrow button on its row on iPhone.
  3. Enter the passphrase.
  4. Choose Restore everything, or Choose… to pick folders.
  5. Choose the mode: Replace All or Merge (see below).

Replace All or Merge

  • Replace All deletes what is on the phone now and puts the backup in its place. If the backup, or your selection, holds only part of the vault, Docsly asks once more before replacing.
  • Merge adds the backup to what is already there. It does not look for duplicates: restoring the same backup twice gives you every document twice.

From a file

A file made with Export to file is opened with Import from file on the same screen, or simply by tapping it. A file import never replaces anything: it only adds. See Open a .docsly file.

If the passphrase is wrong or lost

A wrong passphrase shows Wrong password. Please check and try again. — nothing on the phone changes. A lost passphrase cannot be recovered by anyone, including us: the backup is encrypted with a key that only the passphrase produces. If you still have the old phone, make a new backup there with a passphrase you will remember.

After restoring

  • Recognised text is not part of the backup; Docsly reads the documents again while the app is open.
  • Your PIN stays the one set on this phone; the backup does not carry one.

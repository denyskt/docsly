Как открыть файл .docsly

Файл .docsly переносит документы, папки и их теги из одного Docsly в другой — паспорт для родственника, папку договоров для юриста, всё хранилище для нового телефона. Открывается он только в Docsly, на iPhone, iPad или Android.

Как открыть

  • Нажмите на файл в «Файлах», почте, Gmail или мессенджере и выберите Docsly.
  • Поделитесь им в Docsly из приложения, в котором он пришёл.
  • В самом Docsly: меню «…» на вкладке «Папки» или «Файлы» → Импорт .docsly или Настройки → Данные и хранение → Резервная копия → Импорт из файла.

Что будет дальше

  1. Если у файла есть пароль, Docsly его спросит — тот, что задал отправитель. Если пароля нет, Docsly спросит, импортировать ли файл.
  2. Выберите Импортировать всё или Выбрать…, чтобы взять только часть папок.
  3. Если в файле есть профили, выберите В текущий профиль или По профилям файла. Профили с тем же названием и цветом не дублируются.

Документы добавляются к тому, что у вас уже есть, — ничего не заменяется. Документы, отправленные без папки, попадают во «Входящие». Импорт идёт в то хранилище, которое открыто в этот момент.

О пароле

Когда вы делитесь в .docsly, пароль необязателен. Без него файл откроет любой, у кого есть Docsly и этот файл, поэтому ставьте пароль, если файл идёт через мессенджер или почту, — и передавайте пароль другим путём. У файла из Экспорта в файл пароль есть всегда.

Неверный пароль ничего не меняет: файл остаётся, его можно открыть снова с правильным паролем. Забытый пароль не восстановить — попросите отправителя прислать новый файл.

Если Docsly пишет «Это не файл Docsly»

Файл повреждён или вообще не является файлом .docsly — например, его переименовали. Попросите отправителя поделиться им ещё раз.
